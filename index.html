📋 各タスク・確認事項の詳細マニュアル

社員証・カード類 ↩️ リストへ戻る

  • 社員証は紛失防止のため「鍵付きホルダー」に確実に装着する。
  • 食堂カード等の付随カード類がセットされていることを確認する。

iPad管理 ↩️ リストへ戻る

  • 出勤前にバッテリー残量が100%であることを確認する。
  • 業務中のマニュアル（AQUA）閲覧およびMERS電子署名に使用するため必須。

安全靴・ネックストラップ ↩️ リストへ戻る

  • 安全靴：出勤ドックや作業内容の変動に対応できる適切なものを着用。
  • ネックストラップ：可動部への巻き込まれ防止のため、安全装置付きなど社の安全基準に適合した仕様であることを確認する。

システム・技術情報の確認手順 ↩️ リストへ戻る

  • AQUA：最新のJV協定書および各種整備規程類の改定情報を確認。
  • MERS：当日の担当機材、ドック、DC/ZC体制および割り当てられたオーダー（Routine/Non-routine）を確認。
  • 技術情報：EO（改修指示）、ED（偏務指示）、TSI（技術注意）、TI/TR（不具合情報）、Bulletin（規程補足）の該当有無を目通し。

P-パン（パーツパン）の選定・管理基準 ↩️ リストへ戻る

  • 赤色 CABIN内以外の整備作業全般用（羽田・成田共通）
  • 青・黄・灰 整備作業全般用（羽田） / 青色（成田全般用）
  • 半透明 CABIN内整備用（羽田） / 黄色（成田CABIN用）
  • 黒色（導電性） FUEL TANK内作業専用（TOOL ROOM保管）
  • 記入事項：管理表に「日付・シフト・所属・氏名・使用場所」を記入。当日返却できない（長期借用）場合は養生テープで使用場所等を明記すること。

整備実施体制（CDC/DC/ZC） ↩️ リストへ戻る

  • チーフドックコントローラー（CDC）：作業場全体の工程・安全管理および大扉等の総括。
  • ドックコントローラー（DC）：各ドックの工程・安全・機材管理。
  • ゾーンコントローラー（ZC）：担当ゾーンの作業進捗、DEFECT承認、作業アサイン。
  • KY活動：本日の作業における危険ポイント（高所・重量物・化学物質）をグループ内で共有。

設備・スタンド類の安全点検 ↩️ リストへ戻る

  • 移動式スタンド：昇降後は不意の下降を防ぐため、メカニカルロックが確実に「LOCK POSI」に入っていることを目視点検する。
  • CARGO ACCESS STAND：CARGO DOORとの間に隙間ができないようセット。機体接触防止のため移動時は必ず監視員を配置。
  • CRS車：高所作業に該当するため、運転・操作時は確実に安全ベルトを着用する。
  • 格納庫大扉：操作はCDCまたは許可者のみ。移動範囲内に体を絶対に入れない（特に隙間）。視認性が悪い場合は監視員を配置。

有機溶剤の手配・管理ルール ↩️ リストへ戻る

  • ボトル色分け：ナフサ＝青色、IPA＝黄色、MPK＝赤色
  • 借用手続き：危険物庫の借用台帳に「借用日・シフト・所属・氏名・作業場所・返却予定日」を記入する。
  • 廃油処理：余った溶剤はボトル内に放置せず、各ドックの廃油カートへ廃棄する。

スプレー・テープ類の確認基準 ↩️ リストへ戻る

  • TAG確認：各種スプレーおよびPARTSテープ（CA材：パーマセル、アルミ、両面、オアコン、ガラス、テフロン等）には、一点一様に「SERVICEABLE PARTS TAG」が添付されていること、および有効期限内であることを確認。
  • 作業補助テープ：スコッチ、マスキング、養生、ダンプロン、ビニールテープ等は運航機体に装着不可（作業完了時に必ず除去）。

オイル・グリース・専用カートの取扱 ↩️ リストへ戻る

  • オイル缶：一度開封したオイル缶（1QT）は再保管不可。未使用缶のみ箱に戻す。
  • 専用カート：SKYDROL LD4用、FH6 AW用、HYJET V用など作動油ごとにカートが厳密に分かれているため間違えないこと。
  • オイラー：容器の色と中身（指定オイル）が一致していることを確認。使用後は必ず空にする。

ウエス・保護具の選定基準 ↩️ リストへ戻る

  • オレンジウエス：ENG, APU, FUEL TANKなど特定エリア用。置き忘れ（FOD）防止のためTOOL ROOMで10枚セットで員数管理。
  • ネルウエス：CABIN内のクリーニング用。
  • 靴カバー：CABIN内やWING上面の靴汚れ防止用。

作業中の遵守事項 ↩️ リストへ戻る

  • 溶剤取扱：使用時以外は必ずフタをする。吸入防止のため換気を行う。MPKやCEE-BEEはコロガードペイント（翼）やプラスチック（客室）を侵すため養生を徹底する。
  • 不具合（Non-routine）発生時：自己判断せず直ちにZC/DCへ報告する。

廃棄物・使用済み資材の分別ルール ↩️ リストへ戻る

  • 可燃性溶剤付着ウエス・軍手 ➔ 各ドックの「金属製収納BOX」へ回収・返却。
  • グリス・シーラント・金屑付着 ➔ 再生不可のため各ドックの「ドラム缶」へ廃棄。
  • ネルウエス ➔ 羽田はTOOL ROOMの「洗濯行きBOX」、成田は「一般ごみ」。
  • オレンジウエス ➔ 10枚すべて揃っているか員数カウントの上、袋に入れて返却。
