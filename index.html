P-パン（パーツパン）の種類と管理基準 ↩️ リストへ戻る

  • 羽田作業場における種類と保管場所：
    • 赤色 CABIN内以外の整備作業全般（ANA/BTC共通） / 各DOCK・MAM SHOP
    • 半透明 CABIN内の整備作業（ANA/BTC共通） / 各DOCK REPAIR DECK
    • 青・黄・灰色 整備作業全般（ANA/BTC共通） / 各DOCK
    • 黒色（導電性） TANK内作業（ANA/BTC共通） / TOOL ROOM保管
    • 濃灰色（大） ANA整備作業全般（大物TOOL等） / 各DOCK
  • 成田作業場における種類：
    • 青色 CABIN内以外の整備作業全般 / 各DOCK
    • 黄色 CABIN内の整備作業 / TOOL ROOM保管
    • 黒色（導電性） TANK内作業 / TOOL ROOM保管
  • 管理・借用ルール：
    • 借用時は必ず管理表に「日付・シフト・所属・氏名・使用場所」を記入する。
    • 自DOCKのP-パンが不足している場合は他DOCKから借用可（借用者・日付・個数・作業場を明記）。
    • 当日中に返却できない場合（長期借用）は、養生テープ等で使用場所等を明記して貼り付けておくこと。

整備体制の役割（CDC / DC / ZC） ↩️ リストへ戻る

  • チーフドックコントローラー（CDC）：作業場のDC管理整備工程を総括管理、安全管理、連絡窓口、大扉操作許可、施設・部品使用の総括。
  • ドックコントローラー（DC）：担当ドックの作業工程管理、投入人員数の調整、安全・整備機材の管理。
  • ゾーンコントローラー（ZC）：担当ゾーンの作業工程管理、発生したDEFECTのApproveおよび作業アサイン、記録完了点検（AEへ提出）。自身も作業を実施する。
  • 作業リーダー：作業グループごとに配置。作業者へ直接の作業指示、作業完遂、自らも整備実施。

各種スタンド・設備の安全点検要領 ↩️ リストへ戻る

  • 移動式スタンド（BULK C3 CARGO ACCESS STAND等）：昇降スタンドには不意の降下防止のためメカニカルロックが付いている。STAND上で作業する際は、メカニカルロックが確実に「LOCK POSI（LOCK状態）」に入っていることを必ず目視確認すること。
  • CARGO ACCESS STAND：CARGO DOORにSETする際、DOORとSTANDの間に隙間ができないように設置する。機体に接近・近づける時は必ず「監視員」をつけること。
  • CRS車：高所作業に該当するため、電動自走操作および作業時は必ず設置されている「安全ベルト」を着用すること。（高さ2.2M, 4.2M, 6.2M）
  • 格納庫大扉：操作は「CDC」または「CDCの許可を得た者」とし手動操作に限る。大扉の移動範囲内に身体を絶対に入れないこと（特に隙間）。視認性が十分確保できない場合は監視員を配置。

化学薬品スプレーおよびテープ類（CA材・補助）の確認 ↩️ リストへ戻る

  • スプレー類点検ルール：急冷スプレー、WD-40、STEP21(電装)、ダイチェックスプレー(青/赤/黄)、LPS3(防錆)、LEAK DETECTOR(石鹸水)、ラッカースプレー(合いマーク)、のりはがし(MEK含む)、ジョンソンクルー、青ニススプレー、イカリエアクリーン。一点一様に「SERVICEABLE PARTS TAG」が添付されていること、および有効期限内であることを確認。
  • PARTSテープ（CA材: Consumable A材料）：パーマセルテープ(CABIN FLOOR PNL水進入防止)、アルミテープ(応急処置)、両面テープ(CARPET接着)、オアコンテープ(INSULATION BLANKET補修)、ガラステープ(CARGO目張り)、テフロンテープ(CHAFING防止保護)。一点一様に「SERVICEABLE PARTS TAG」が添付されていること。
  • 整備作業補助テープ：スコッチ、マスキング、養生、ダンプロン、ビニールテープ。整備作業補助テープは運航する機体には装着・残留させてはならない（作業完了時全回収）。

油脂・オイル・専用カート・オイラーの管理基準 ↩️ リストへ戻る

  • エンジン/IDGオイル：BP TURBO OIL 2380, ESSO TURBO OIL 2380 (120-052), BP TURBO OIL 2197, ESSO TURBO OIL 2197 (120-212), MOBIL JET OIL II (120-023)。各DOCK油脂庫保管。
  • 作動油（FLUID）：AERO SHELL FLUID 3 (120-002), FLUID 41 (120-209), FLUID 12 (120-049), Hydraunycoil FH6 AW, SKYDROL LD4。
  • グリース類：ASG7(120-088一般), ASG14(120-009 TANK PANEL), ASG16(120-010 CABLE), ASG17(120-011 T/R SHAFT), ASG22(120-195 BEARING), ASG33(120-219 優先使用一般), ROYCO11MS(120-185 GEAR), SHC100(120-231 WHEEL BEARING), ASG33MS(120-236 T/R SHAFT)。最新規程を確認。
  • 専用カートの誤用防止：SKYDROL LD4、FH6 AW、HYJET V用の専用カートがそれぞれ存在する。作業時は絶対にカートを間違えないこと。中身を確実に確認する。
  • オイラーの注意：オイラーは容器の色別に中身が指定されている。補充時は決められた色に従い、使用後は必ず中身を「空」にすること。

各種保護材・備品・台車の選定 ↩️ リストへ戻る

  • ウレタンマット：機体・PARTSの保護用。汚れているものや溶剤・FLUIDが染み込んでいるものがあるため、安易にWING上面やCABIN内に持ち込まないこと。
  • 漏洩処置材：オイルプロッター（FLUID吸収用紙）、オイルドライ（FLUID吸収粉末）。
  • 台車の選定：一般運搬は手押し台車。重量物運搬はNo.2 DOCK台車置き場の「重量物専用台車（黄色）」。コンポーネント運搬はNo.2 DOCK配置の「COMPONENT専用台車（白い台車に青ウレタン敷き）」を使用。

ウエス・手袋・靴カバーの選定基準 ↩️ リストへ戻る

  • ウエス各種：
    • レンタルウエス：一般整備用（クリーニングに出す）。
    • ネルウエス：CABIN内CLEANING用。
    • フィルターウエス：SERVICING時のFLUIDろ過用。
    • 白ウエス：PAINT/SEALANT用（使い捨て）。
    • オレンジウエス：ENG、APU、FUEL TANK内作業専用。置き忘れ（Engine Fire原因等）防止のためTOOL ROOMで10枚セットで員数管理。使用後は袋に入れて返却。
  • 靴カバー：CABIN内やWING上面等、安全靴の汚れを機体側へ付着させないために着用（高圧洗浄時の滑り止め代用）。汚れていないものを使用すること。

溶剤使用時の遵守事項および応急処置 ↩️ リストへ戻る

  • 使用上の遵守事項：
    1. 容器は使用中でなければかならずフタをすること。
    2. 長時間、有機溶剤蒸気の吸入をさけること（換気の良い場所で作業、かかった着衣は交換、必要に応じマスク着用）。
    3. 長時間、素手で溶剤にさわらないこと（ゴーグル・手袋着用）。
    4. 火気に十分注意すること。（ガラスクルー使用時はTSI 00-25-L076参照）
  • 応急処置：眼に入った場合：清浄な水で最低15分洗浄し医師の手当。皮膚付着：水と石鹸で洗う。吸入：新鮮な空気の場所へ移し毛布等で保温・安静、直ちに医師の手当。飲み込み：無理に吐かせず医師の手当（口内は水で洗う）。
  • 特記事項：MPKは劇物。MPKおよびCEE-BEEはコロガードペイントを侵すためWING, H-STABへ安易に持ち込まない。MPKはプラスチックPARTSも侵すためCABIN内持ち込み注意。

オイル缶の開封・使用ルール ↩️ リストへ戻る

  • オイル缶（1QT）は、使用する分だけ箱から出して使用すること。
  • 一度開封したオイル缶は保管棚に戻してはならない（品質維持のため）。未使用分のみ必ず箱の中に戻すこと。

使用済みウエス・軍手の廃棄・回収分別ルール ↩️ リストへ戻る

  • 金属製収納BOXへ返却するもの：有機溶剤（FUEL, MPK, IPA等）が付着した可燃物の軍手・ウエス。
  • ドラム缶へ廃棄するもの：グリスが多量に付着したもの、シーラANTが付着したもの、金屑が付着したもの（洗濯不可能なため全廃棄）。
  • 個別廃棄・返却ルート：ネルウエス（羽田）はTOOL ROOMにある洗濯行きBOXへ返却。ネルウエス（成田）は一般ごみへ廃棄。レンタルウエス/軍手でPAINT/SEALANT・切り粉・有害物質等が付着した場合は廃棄処理。オレンジウエスは持ち込み枚数（10枚）が揃っているか員数確認し、袋に入れてTOOL ROOMへ返却。

余剰溶剤およびオイラーの処理 ↩️ リストへ戻る

  • 使用後、ボトル内に余った有機溶剤（MPK, IPA, ナフサ等）は、各DOCKにある「廃油カート」へ廃棄すること。
  • オイラー（注油器）使用後は、必ず中身を「空」にして保管場所へ戻すこと。

検査の種類と実施体制 ↩️ リストへ戻る

  • 検査（実質検査）：耐空性に特に影響を及ぼす大修理・改造、または誤作業が運航に重大影響を与える作業について、作業者以外の資格保持者（第三者）が合否判定を行う。
  • 受領検査：使用者から航空機/装備品を受領する際の受入検査（過去の整備履歴等を入手）。
  • 領収検査：整備工程委託時、発注要求通り適切に実施されているかをAE/LAE資格者が書類および実質検査で確認する。

終業ブリーフィングおよび不具合レビュー ↩️ リストへ戻る

  • 当日の整備進捗報告および未完了作業の次シフト/翌日への申し送り実施。
  • 不具合事象のレビュー：過去1年以内に発生した主要不具合事象（CAT-I、CAT-II等）の発生原因・対策について周知を受け、日常作業の安全品質向上につなげる。
